# Fritzing part assets

The SVGs in this directory are derived without modification from
[`fritzing/fritzing-parts`](https://github.com/fritzing/fritzing-parts) at commit
`27535f2fd02097be9bed229b75aa8e9be282a4a0`.

Source part definitions used: standard breadboard, GY-521 / MPU6050, HC-SR04,
ACS712 Low Current Sensor Board v1.2, Dagu 9 g servo (physical equivalent),
generic axial resistor, and Schottky diode.

The upstream graphics are licensed under CC BY-SA 3.0. The AHEA UI identifies
the exact represented hardware separately where the Fritzing repository lacks
an exact module (notably ESP32-S3-DevKitC-1 v1.1, bare DHT11, and the 0–25 V
passive voltage divider module).
